## 👋 This is the freeupscale community tracker

The site's code is private. **This repo is the public home for bug reports and feature requests.**

## 🐞 Found a bug? 💡 Have an idea?

[**→ Open an issue**](https://github.com/freeupscale/feedback/issues/new/choose)

- **Bug report**: something broken or unexpected. Please include your browser, device and the page you used.
- **Feature request**: a feature, a format or a language you'd like. Tell us the problem you're trying to solve.
- Search [existing issues](https://github.com/freeupscale/feedback/issues) first, and 👍 the ones you care about.

> ⚠️ **Don't attach private images.** If a picture is needed to show the bug, use one you are fine sharing publicly.
